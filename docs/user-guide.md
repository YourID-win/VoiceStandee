# VoiceStandee 使い方の案内(配布用の文面)

Discord に貼る・配信の概要欄に載せる用の文面です。`【連絡先】` の部分は、載せる前に書き換えてください。

---

## 短い告知文(Discord の1メッセージに収まる長さ)

```
🎙 VoiceStandee(ボイススタンディ)

ボイスチャンネルで話している人の「立ち絵」が、OBS の配信画面に並びます。
話している人だけが明るくなって、軽く跳ねます。立ち絵は一度登録するだけ。コラボのたびに設定し直す必要はありません。

【使い方】
1. /立ち絵 登録 で、画像を付けて送る(PNG / JPG / GIF、3MBまで)
2. 配信する人は /立ち絵 obs で URL を出して、OBS の「ブラウザ」ソースに貼る
3. ボイスチャンネルに入ると、Bot が自動で入ります

【安心してほしいこと】
・Bot は「誰が話しているか」だけを見ています。音声を聞いたり、録音・保存したりはしません。
・立ち絵は、自分で消せます(/立ち絵 削除)。

詳しい案内: (ここにリンクか、案内チャンネル)
困ったとき: 【連絡先】
```

---

## 詳しい案内

### できること

- ボイスチャンネルにいる人が、立ち絵で、OBS の配信画面に並びます。
- 話している人は明るくなり、軽く跳ねます。黙っている人は、少し暗くなります。
- 立ち絵を登録していない人は、Discord のアイコンが表示されます。
- 見た目(大きさ、跳ね方、並びなど)は、専用の設定ページで、実際の画面を見ながら調整できます。

### 使い方

#### みんな(立ち絵を使いたい人)

`/立ち絵 登録` に、画像を付けて送ります。

- そのサーバーでは、その画像が、あなたの立ち絵になります。サーバーごとに、別の画像を登録できます。
- Bot との DM で登録するか、オプションの「共通」を付けると、全サーバー共通の立ち絵になります。
- 表示される順番: **そのサーバー用 → 共通 → Discord のアイコン**
- 画像は、PNG / JPG / GIF(GIF は、最初の1コマだけを使います)、3MB まで。背景が透明な PNG が、おすすめです。
- 画像の透明な余白は、自動で切り取られます。大きすぎる画像は、縮小されます。

#### 配信する人

1. `/立ち絵 obs` で、あなた専用の URL を出します。
2. OBS の「ソース」に、「ブラウザ」を追加し、URL を貼ります。幅と高さは、配信画面と同じ(例: 1920 × 1080)にします。
3. URL の末尾に `/settings` を足した、設定ページを開き、見た目を調整します。変更は、すぐ OBS に反映されます。

**この URL は、あなた専用の鍵です。他の人には見せないでください。** 漏れたかもしれないときは、`/立ち絵 obs` で「再発行」を選ぶと、古い URL は使えなくなります。

Bot は、あなたが(Bot のいるサーバーの)ボイスチャンネルに入ると、自動で入ります。自動で入ってほしくないときは、`/立ち絵 自動参加` で、オフにできます。

### コマンド一覧

| コマンド | 内容 |
|---|---|
| `/立ち絵 登録` | 立ち絵を登録(このサーバー用。「共通」を付けると全サーバー共通) |
| `/立ち絵 確認` | 今、このサーバーで使われる立ち絵を見る |
| `/立ち絵 削除` | 登録した立ち絵を削除する |
| `/立ち絵 obs` | OBS 用の URL を出す(再発行もできる) |
| `/立ち絵 自動参加` | ボイスチャンネルに入ったときの、自動参加のオン / オフ |
| `/立ち絵 非表示` | あなたの OBS 表示で、特定の人の立ち絵を、Discord のアイコンに置き換える |
| `/立ち絵 非表示解除` | 上を元に戻す |
| `/立ち絵 報告` | 不適切な立ち絵を、Bot の管理者に知らせる |

どの返事も、**あなたにだけ**見えます。

### Bot が見ているもの・見ていないもの

- Bot は、通話の音声データを受け取りますが、**聞いたり、再生したり、解析したり、録音・保存したりは、しません。** 使っているのは、「誰のデータが、いつ届いたか」だけです(話している人を知るため)。
- 通話の内容は、Bot から、どこにも送られません。
- 保存しているのは、次のものだけです。
  - 登録された立ち絵の画像
  - OBS 用 URL の鍵と、見た目の設定
  - 非表示にした人の Discord ID
  - 管理のための記録(誰が、いつ、どのサーバー用に登録したか。画像そのものは含みません)
- 立ち絵は、`/立ち絵 削除` で、いつでも消せます。
- 仕組みは、ソースコードを公開しているので、確認できます: https://github.com/YourID-win/VoiceStandee

### 立ち絵のルール

立ち絵は、配信の画面に、そのまま映ります。次のような画像は、登録しないでください。

- 自分が使ってよいと言えない画像(他の人の作品を、許可なく使うなど)
- 暴力的・性的な画像、差別的な画像、他の人を傷つける画像
- 個人情報が写っている画像

不適切な画像を見つけたら、`/立ち絵 報告` で、Bot の管理者に知らせてください(1時間に3件まで)。管理者は、画像を削除し、必要なら、その人の登録を禁止します。
配信する人は、管理者の対応を待たずに、`/立ち絵 非表示` で、自分の OBS 表示から、その人の立ち絵を外せます。

### 困ったとき

**Bot がボイスチャンネルに入ってこない**

- ボイスチャンネルが、非公開の設定(`@everyone` に「チャンネルを見る」「接続」を許可していない)になっていると、Bot も入れません。VoiceStandee に、そのチャンネルの「チャンネルを見る」と「接続」を許可してください。
- 配信する人が、`/立ち絵 obs` を、一度も使っていない場合も、Bot は入りません。
- Bot が、そのサーバーに、まだ招待されていない場合も、入れません。
- Discord の制限で、Bot は、1つのサーバーで、1つのボイスチャンネルにしか入れません。

**OBS に何も映らない**

- URL を、OBS の「ブラウザ」ソースに貼ったか。幅と高さを、設定したか。
- 配信する人が、ボイスチャンネルに入っているか(入っていない間は、何も映りません)。
- Bot が、そのボイスチャンネルに入っているか(入っていないと、立ち絵は映りますが、話しても動きません)。

**話し終わったあと、少しの間、動き続ける**

- 設定ページの「余韻」を、短くします。「止まり方」を、「すぐ止める」にすると、さらに短くなります。ただ、Discord 側が、話し終わったあとも、短い間、音声を送り続けるため、完全にはなくせません。

**自分の立ち絵が、変わらない / 違う画像が出る**

- 立ち絵は、**そのサーバー用**の登録が、共通より優先されます。`/立ち絵 確認` で、今使われている画像を見られます。

連絡先: 【連絡先】
